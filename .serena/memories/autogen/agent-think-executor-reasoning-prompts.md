==== 1. AssistantAgent System Message ====

配置位置：AssistantAgentConfig 和 AssistantAgent.__init__()

system_message 参数：
- 类型：str | None
- 默认值：None（可选，不强制设置）
- 使用方式：
  ```python
  system_message: str | None = None
  ```
- 当设置时，会被转换为 SystemMessage 对象列表：
  ```python
  self._system_messages: List[SystemMessage] = []
  if system_message is None:
      self._system_messages = []
  else:
      self._system_messages = [SystemMessage(content=system_message)]
  ```
- 推荐用法：
  ```python
  agent = AssistantAgent(
      name="assistant",
      model_client=model_client,
      system_message="You are a helpful assistant."
  )
  ```

==== 2. CodeExecutorAgent System Message ====

DEFAULT_SYSTEM_MESSAGE：
"You are a Code Execution Agent. Your role is to generate and execute Python code based on user instructions, ensuring correctness, efficiency, and minimal errors. Handle edge cases gracefully."

用途：
- 当 model_client 被提供时，该消息被用作系统提示
- 仅用于代码生成和执行流程
- 可以通过构造函数参数覆盖

==== 3. SocietyOfMindAgent 的多Agent协作提示词 ====

DEFAULT_INSTRUCTION：
"Earlier you were asked to fulfill a request. You and your team worked diligently to address that request. Here is a transcript of that conversation:"

DEFAULT_RESPONSE_PROMPT：
"Output a standalone response to the original request, without mentioning any of the intermediate discussion."

使用流程：
1. instruction 被添加到内部团队消息之前
2. response_prompt 用于最终响应生成
3. 这些提示词都假定角色为 'system'

设计意图：
- 将内部团队讨论与最终输出分离
- 提示模型生成独立的响应而不暴露内部协作细节

==== 4. ThoughtEvent 和 Reasoning 处理 ====

ThoughtEvent 类定义（messages.py, 第519行）：
```python
class ThoughtEvent(BaseAgentEvent):
    """An event signaling the thought process of a model.
    It is used to communicate the reasoning tokens generated by a reasoning model,
    or the extra text content generated by a function call."""
    
    content: str
    type: Literal["ThoughtEvent"] = "ThoughtEvent"
```

Reasoning 模型上下文（ReasoningModelContext）：
- 位置：/Users/niko/autogen/python/packages/agbench/benchmarks/HumanEval/Templates/AgentChat/reasoning_model_context.py
- 作用：过滤 AssistantMessage 中的 thought 字段，防止推理内容反复输入
- 实现：
  ```python
  async def get_messages(self) -> List[LLMMessage]:
      messages = await super().get_messages()
      messages_out = []
      for message in messages:
          if isinstance(message, AssistantMessage):
              message.thought = None
          messages_out.append(message)
      return messages_out
  ```

OpenAI 客户端 Thinking 支持：
- 支持从 choice.message.thought 提取思考内容
- 支持从 reasoning_content 字段获取推理内容（如 R1 模型）
- 支持从 R1 模型返回的内容中解析推理部分
- 通过 parse_r1_content() 函数分离推理和回答

==== 5. Tool Call 相关的 Reasoning ====

Tool Call Summary Format：
- 默认值："{result}"
- 位置：AssistantAgent 的 tool_call_summary_format 参数
- 使用场景：当 reflect_on_tool_use=False 时，用于格式化工具执行结果
- 可用变量：{tool_name}, {arguments}, {result}

示例：
```python
agent = AssistantAgent(
    name="assistant",
    model_client=model_client,
    tool_call_summary_format="{tool_name}: {result}"
)
```

Tool Call Reflection 流程：
- 当 reflect_on_tool_use=True 时：工具结果被提交给模型进行二次推理
- 当 reflect_on_tool_use=False 时：工具结果直接格式化为响应
- reflect_on_tool_use 在使用 output_content_type（结构化输出）时默认为 True

==== 7. Swarm (HandOff) 架构中的隐式提示词 ====

Swarm 机制：
- 基于 HandoffMessage 中的 target 字段确定下一发言人
- 不依赖于显式的选择提示词，而是依赖于 agent 的 system_message
- 每个 agent 的 system_message 应包含其角色定义

示例：
```python
agent_alice = AssistantAgent(
    name="Alice",
    model_client=model_client,
    system_message="You are Alice and you only answer questions about yourself."
)

agent_bob = AssistantAgent(
    name="Bob",
    model_client=model_client,
    system_message="You are Bob and your birthday is on 1st January."
)

team = Swarm([agent_alice, agent_bob])
```

==== 8. MagenticOne 中的高级协调提示词 ====

Orchestrator 级别的提示词（位置：_magentic_one/_prompts.py）

1. ORCHESTRATOR_TASK_LEDGER_FACTS_PROMPT：
   - 用途：提取任务中的已知事实、需要查找的事实、需要推导的事实、教育性猜测
   - 返回格式：JSON，包含 reason 和 answer 字段

2. ORCHESTRATOR_TASK_LEDGER_PLAN_PROMPT：
   - 用途：基于团队成员和事实制定计划
   - 指令：简洁的项目符号形式，无需涉及所有成员

3. ORCHESTRATOR_PROGRESS_LEDGER_PROMPT：
   - 用途：评估进度、检测循环、选择下一发言人、给出指令
   - 返回 JSON 包含：
     - is_request_satisfied (reason + boolean)
     - is_in_loop (reason + boolean)
     - is_progress_being_made (reason + boolean)
     - next_speaker (reason + string)
     - instruction_or_question (reason + string)

4. ORCHESTRATOR_FINAL_ANSWER_PROMPT：
   - 用途：基于完整对话生成最终答案
   - 指令：向用户发言方式

==== 9. 提示词设计模式总结 ====

1. 系统消息模式：
   - 角色定义（role definition）
   - 可选的（None 时跳过）
   - 存储为 SystemMessage 对象列表

2. 指令提示词模式：
   - 用于多 agent 协作中的中间步骤
   - 通常包含上下文和任务描述
   - 使用模板变量注入动态内容

3. 选择器提示词模式：
   - 引导模型从给定选项中选择
   - 尽可能简洁
   - 指定输出格式（仅返回名称或 JSON）

4. 反思提示词模式：
   - 用于工具调用结果的处理
   - 可自定义格式字符串
   - 支持 reason + answer 的结构化输出

5. 推理提示词模式：
   - ThoughtEvent 用于捕获思考过程
   - 思考内容与执行结果分离
   - 支持推理模型（如 OpenAI o1/o3、Deepseek R1）

==== 10. 关键配置参数 ====

AssistantAgent 主要参数：
- system_message: 初始系统提示（可选）
- tool_call_summary_format: 工具结果格式（默认 "{result}"）
- reflect_on_tool_use: 是否对工具结果进行反思（bool）
- output_content_type: 结构化输出类型（可选）
- model_client_stream: 流式输出模式（bool）

SocietyOfMindAgent 主要参数：
- instruction: 内部团队消息前置指令
- response_prompt: 最终响应生成提示

SelectorGroupChat 主要参数：
- selector_prompt: 用于选择发言人的提示词

CodeExecutorAgent 主要参数：
- system_message: 代码执行相关的系统消息（默认值已定义）
